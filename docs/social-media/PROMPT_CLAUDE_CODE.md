Você vai construir o módulo Social Media com acesso isolado dentro do Pró-Labore, o sistema comercial da MM Negócios & Veículos que está neste repositório.

Copie a pasta `docs/social-media/` para o repositório antes de começar. Ela contém:
- `ESPECIFICACAO_SOCIAL_MEDIA.md`: a fonte da verdade para regras, dados, cálculos e comportamento;
- `referencia-visual/`: 14 arquivos HTML com o protótipo aprovado, tela por tela. É a fonte da verdade para layout, textos e visual. Leia a seção 0 da especificação para entender a sintaxe desses arquivos.

Regras de trabalho:
1. Leia a especificação inteira e todos os arquivos de `referencia-visual/` antes de escrever qualquer código.
2. Mapeie o repositório (stack, rotas, autenticação, papéis, CRM, estoque, integração atual com o Instagram, design system) e me entregue um plano de encaixe. Aponte conflitos e as adaptações propostas. Espere minha aprovação do plano.
3. Construa na ordem das fases da seção 18. Ao fim de cada fase: rode os testes, compare com os protótipos, marque o checklist daquela fase e me mostre o que ficou pronto antes de seguir.
4. Nada é opcional. Tudo que está na especificação e nos protótipos deve existir no produto, inclusive a Fase 6. Os itens marcados [CONFIRMAR COM O JOÃO] são perguntas para mim: faça todas de uma vez no plano, não no meio do trabalho.
5. Os números dos protótipos são ilustrativos. No produto, todo número vem do banco ou das APIs. A IA nunca inventa números e nunca recebe custo, margem ou dados financeiros.
6. Reaproveite componentes, tokens e integrações que já existem no Pró-Labore em vez de duplicar.
7. Mantenha um arquivo `docs/social-media/PROGRESSO.md` atualizado, com o checklist marcado e as decisões tomadas.

Comece pelos passos 1 e 2.
